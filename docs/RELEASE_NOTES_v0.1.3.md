# Book Editorial Tracker v0.1.3

## Highlights

- The desktop application and installer are now named **Book Editorial Tracker**.
- Installation and updates create standard Start-menu and Desktop shortcuts.
- Uninstall removes the application shortcuts.

## Installation

Download and run `Book Editorial Tracker-0.1.3 Setup.exe`.

The installer remains unsigned for private distribution. Windows may show a SmartScreen warning; verify the release source before installing.

## Compatibility

This is an in-place update: it keeps the same Firebase project and existing local application data.
