# Editorial Review Tracker v0.1.2

This is the first private Windows desktop release for the small editorial team.

## Highlights

- Live Firestore-backed chapter tracking for authenticated editors.
- Email/password sign-in, password reset, and optional Google sign-in.
- Manual chapter entry, CSV import/export, and accessible bulk deletion.
- Local JSON backup and CSV export using a Windows Save As dialog.
- Working-folder audit with dated reports and immutable audit events.
- Branded desktop icon, native Windows controls, and external links opening in the default browser.

## Installation

Download and run `Editorial Review Tracker-0.1.2 Setup.exe`.

This installer is intentionally unsigned for private distribution. Windows may show a SmartScreen warning; verify the release source before installing.
